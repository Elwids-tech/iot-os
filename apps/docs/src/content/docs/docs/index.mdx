## What these docs describe

They describe the hosted service as it runs today. The reference and the user guides are generated from the release customers use, and features that aren't switched on for the hosted service aren't documented. To report something that doesn't match what you see, use the link at the bottom of any page.

To use the API you need an application and a token, created in the portal under **Connect → Integrations** by someone with permission to manage devices. Keep the token on your server.
