## Purpose
**Help** explains documented system behavior. The profile and workflow assistants prepare reviewed authoring suggestions when their capabilities are available.

## Before you start
AI must be enabled on the server and have remaining allowance. Reading guides and searching Help remain available without AI.

## Steps
1. Choose **Assistant** beside **Help** at the top of any page. On a page with its own assistant, such as the automation editor or a device profile, **Ask** opens on it. Elsewhere **Ask** opens on suggestions for that page.
2. Choose a suggestion, or choose **Suggestions** to return to them. **Create a device profile** and **Ask how to use IoT OS** work from any page; an automation suggestion opens a new automation with its request ready in the editor's assistant.
3. In Help, choose **This page** for contextual guidance or **All guides** to search. For a usage question, choose **Ask how to use IoT OS** or one of the page's questions, then follow cited article headings inside the panel.
4. For profile authoring, describe the profile or provide relevant documentation. Review each proposal before saving a section.
5. For automation authoring, edit the request and send it. Review the proposal and choose **Use this draft**, then save and review activation separately.
6. Stop a response or delete your private conversation when needed.

## Expected result
Help answers use approved guides and page context. Authoring suggestions require review; a chat message saying yes does not authorize publication, activation, or commands.

## Troubleshooting
Help cannot inspect live device data or your unsaved form. If documentation is insufficient it should say so. When AI is unavailable, continue with the guides. Profile publication and workflow activation remain explicit workflows.

If a device was reconfigured after an automation was saved, the automation assistant updates its bindings in the proposal; review them before using the draft. If a device was deleted, rebind or remove it in the editor before asking. Each new automation starts its own conversation.
