# Shared Packages

Shared packages may be consumed by React applications but must not depend on an application workspace.

- `ui` — platform-owned shadcn components and design tokens
- `api-client` — generated TypeScript client for the Laravel OpenAPI contract
- `auth` — shared authentication and tenant context
- `agent-ui` — agent conversation, tool-result, and approval components
- `charts` — governed telemetry visualizations
- `config` — shared TypeScript, lint, and test configuration
